# ⚡ AI Social Media Hub

*A smart, multilingual content generator powered by Google Gemini.*

**[ 🔴 CLICK HERE FOR LIVE DEMO ](https://aisocialmedia.streamlit.app/)**

---

## 🌟 Overview
This application transforms raw ideas into high-impact, multi-platform social media campaigns in seconds. Built with a focus on a clean user interface and seamless experience, it serves as a modern tool for digital creators, marketers, and teams.

## ✨ Key Features
- 🌍 **Fully Multilingual:** Both the UI and AI content generation are available in 5 languages (English, Romanian, French, German, Spanish).
- 🎭 **Dynamic Tone Adaptation:** Choose between Professional, Casual, Bold, or Educational. The AI adapts the entire structure and hook, not just the vocabulary.
- 📱 **Multi-Platform Output:** Perfectly tailored formats for LinkedIn, X (Twitter), and Instagram in a single click.
- 🧪 **Offline Test Mode:** A fully functional testing environment to explore the UI and formatting without needing an API key.
- 📥 **Instant Export:** Download your generated campaigns directly as `.txt` files.

## 🛠️ Tech Stack
- **Frontend & App Logic:** Python, Streamlit
- **AI Engine:** Google GenAI SDK (Gemini 3.8 Flash)
- **Design:** Custom CSS, minimalist dark-mode UI with soft gradients, featuring the Plus Jakarta Sans font.
